# 🛒 Murali Krishna General Store - Smart POS & Inventory Management Suite

A lightweight, high-performance, mobile-responsive Point of Sale (POS) and inventory tracking application built for independent retail merchants. This app streamlines checkout billing counters, eliminates calculations by hand, and monitors store performance metrics with zero server costs.

🚀 **Live Demo:** https://siddharda-reddy.github.io/murali-krishna-store/

## ✨ Core Features
- **Android Mobile Optimization:** Built using a mobile-first fluid responsive grid layout, complete with touch-friendly navigation drawers designed specifically for Android smartphones and tablets.
- **Instant Search Bar Integration:** Offers live search-as-you-type functionality on the billing desk, replacing traditional slow dropdown selection modules.
- **Smart Category Constraints:** Automatically enforces standard metrics based on inventory segments (e.g., locking Grains to KG/Grams calculations, and Packaged Beverages to individual unit processing).
- **Dual Calculation Architecture (Sliding Toggle Pill Button):**
  - *Standard Mode:* Input weight (grams) or unit counts to compute total customer cost price.
  - *Reverse Cash Mode:* Input target currency values (₹) to instantly generate exact weights to scale and hand over to the customer.
- **Automated Bookkeeping Ledger:** Tracks gross operational revenues, calculating dynamic profit margins in real-time.
- **Autopilot Stock Management:** Automatically deducts quantitative parameters from inventory totals upon clearing checkouts.
- **Interruption-Free User Flow:** Eliminated alert dialogues and validation popups to ensure high-speed operation on the shop floor.

## 🛠️ Technical Stack
- **Frontend Architecture:** Vanilla Semantic HTML5, CSS3 Custom Properties (Variables)
- **Programming Engine:** Vanilla JavaScript (ES6 Modules/Event Loops)
- **Data Persistence Layer:** Browser-native LocalStorage Key-Value Databases (Zero-Loss across page refreshes)
